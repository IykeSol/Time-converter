# ⏱ IykeSol Convert Calculator

> Convert hours, minutes and seconds to decimal hours with precision. Sum multiple time entries instantly.

## Features

- **Time → Decimal** — Enter `HH:MM:SS` and get the decimal equivalent (e.g. `1:30:00` → `1.500 hrs`)
- **Sum & Convert** — Add multiple time entries and see the running total in both time and decimal format
- **History** — Recent conversions are saved locally (localStorage) across sessions
- **No dependencies** — Pure HTML, CSS & JavaScript. No install needed.

## Usage

Just open `index.html` in any browser. No server required.

## Tech Stack

- HTML5 / Vanilla CSS / Vanilla JavaScript
- Google Fonts: Space Grotesk + Manrope
- localStorage for history persistence
